About The EVI Project

This project aims to give teachers the resources they need to deliver high-quality Explicit Vocabulary Instruction (EVI) of critical words.

3teaching slides per word
16CFU retrieval slides, easy to hard
DIscript included on every slide

There are many great ways to teach vocabulary, so what type of instruction is this?

Explicit Vocabulary Instruction is a teaching method built on structured, systematic instruction in critical vocabulary. It aims to maximise student engagement and success by making sure students develop a deep understanding of word meanings. It does this through direct teaching that combines key features of oral and written language, frequent checks for understanding, and systematic scaffolding to reduce reliance on guesswork.

What's included in the resource?

In the folder, you'll find a Google Slides file for each word. Each file includes 3 teaching slides and 16 "Check for Understanding" (CFU) retrieval slides. The CFU slides are arranged from easy to hard, so you can use meaningful, effortful spaced retrieval of the word in a range of contexts. All slides include a DI script you can follow to maximise efficiency and impact.

A little caveat...

These slides were created with the help of 'Chatty' (ChatGPT) along with some other coding. There may be minor errors, and the images may not always match perfectly, because I'm using a free image API that fetches the most relevant visuals. Please skim through each slide before teaching and adapt it to suit your needs.
